# TikTok KOL 建联智能助手

一个对话式的 AI 驱动的 TikTok 红人采集和建联工具。从产品理解、搜索策略、数据采集到优先级排序的端到端自动化。

## 工具特点

✨ **对话式体验**
- 不是工作表单，而是像和 KOL 运营主管聊天一样的交互
- 自动追问有价值的后续问题，根据产品特性智能调整策略

🧠 **AI 驱动的智能推荐**
- 不是查表推荐关键词，而是 Claude 分析产品特性、目标市场、行业趋势后的推理
- 多维度博主评分（内容相关度、粉丝匹配、合作潜力、增长趋势）
- 可根据用户优先级自动调整权重（快速启动/转化优先/品牌建设）

⚡ **端到端自动化**
- 从产品诊断 → 搜索策略 → TikHub 采集 → 智能排序 → 建联建议
- 最少化用户干预（通常只需 2-3 次确认）
- 快速输出可操作的建联名单

📊 **专业的输出格式**
- CSV 建联名单（可直接导入 Excel）
- HTML 可视化报告（浏览器打开即用）
- 建联建议文档（分层计划 + 邮件模板）
- 采集中心首页（管理历史记录）

## 使用流程（4 个环节）

### 环节 1：产品诊断（对话式）

你告诉 Agent 你的产品（品牌、品类、目标市场、卖点等），Agent 会：
- 自动追问有价值的后续问题
- 推理产品定位和目标人群
- 建议搜索维度

**例子：**
```
你: "我有个护肤面膜，补水的，高端定位，北美市场"
Agent: "很好！快速了解一下，这个面膜的核心卖点是什么？
        是纯补水，还是也关注抗衰？有竞品品牌吗？"
```

### 环节 2：策略确认（AI 推荐）

Agent 基于产品诊断，生成 5-8 个高质量关键词，包括：
- 品类词、竞品词、场景词、人群词、趋势词
- 每个词的搜索意图和预期博主类型
- 采集目标和质量预估

你可以确认、修改或扩展这些关键词。

### 环节 3：数据采集（自动执行）

Agent 调用 TikHub API：
1. 用视频搜索发现创作者（而不是用户搜索，质量更高）
2. 从视频的作者字段提取博主
3. 调用用户资料接口获取完整 Bio 和邮箱
4. 去重和初步筛选

**输出：** 采集进度和最终博主数

### 环节 4：智能排序（AI 多维评分）

Agent 对每位博主进行 4 维度评分：

| 维度 | 说明 | 权重范围 |
|------|------|---------|
| 内容相关度 | 博主内容与产品的匹配程度 | 30-50% |
| 粉丝匹配度 | 博主粉丝与目标用户的契合 | 20-35% |
| 合作潜力 | 联系难度、合作意愿、活跃度 | 15-40% |
| 增长趋势 | 账号增长阶段和发展方向 | 5-10% |

权重根据用户的优先级自动调整：
- **快速启动**：优先合作潜力（邮箱、活跃度）
- **转化优先**：优先内容相关度和粉丝匹配
- **品牌建设**：优先内容相关度和粉丝匹配

**输出：** A/B/C 分层的优先级排序名单

## 关键特性

### 1. 实时策略调整

采集完成后，如果你想：
- 增加某个关键词的采集量
- 改变评分权重（如"转化优先"）
- 重新排序

Agent 可以快速重新执行，**无需从头开始**。

### 2. 已有博主评估

如果你已经有感兴趣的博主，可以：
- "帮我评估这 5 个博主是否适合我的产品"

Agent 会对这些博主逐个评分，给出建议。

### 3. 透明的评分理由

每个博主的排序都有具体理由，例如：
```
@sarah_beauty_tips: 90.5 分
- 内容相关度 92：发布 8+ 个面膜教程，bio 明确写"skincare expert"
- 粉丝匹配度 88：粉丝 95% 是 25-40 岁职业女性
- 合作潜力 95：有邮箱、bio 明确"open to collaboration"、最近每周发 4+ 视频
- 增长趋势 75：月增 2.5%，互动率稳定 4.2%
```

你能看懂为什么这个博主排在前面。

## 运营建议

### 优先联系顺序

1. **第一批：A 级有邮箱的博主**（预期 12-15 位）
   - 邮件回复率最高（40-50%）
   - 预期成功率 30-40%

2. **第二批：A 级无邮箱的博主**（预期 20 位左右）
   - 需要通过私信
   - 回复率较低（20-30%），但仍值得尝试

3. **第三批：B 级博主**
   - 当 A 级反馈不足时启动
   - 预期成功率 20-30%

### 质量对比

通常，**竞品词搜出的博主质量最高**：
- 已经在推竞品 → 有购买力 → 转化率最高
- 建议优先联系竞品词来源的 A 级博主

### 时间规划（参考）

| 阶段 | 耗时 | 行动 |
|------|------|------|
| 环节 1-2 | 10-15 分钟 | 产品诊断 + 策略确认 |
| 环节 3 | 5-10 分钟 | 数据采集（TikHub 批量搜索） |
| 环节 4 | 3-5 分钟 | AI 评分和排序 |
| **总计** | **20-30 分钟** | 从产品到建联名单 |

## 技术细节

### API 和工具

- **TikHub API**：用于搜索 TikTok 视频和获取博主资料
- **Claude API**：用于产品分析、关键词生成、博主评分
- **TikTok Web**：用于获取博主的完整 Bio 和邮箱

### 邮箱提取率

- 从 bio 直接提取：~15-20%
- 访问博主落地页提取：+30-35%
- **综合邮箱获取率：45-55%**（取决于目标博主的开放程度）

### 采集成本估算

采集 5 个关键词、目标 400 位博主：
- TikHub API 请求数：~415 次
- 通常在标准配额范围内
