# AI 提示词库（Intelligence Prompts）

本文件包含 4 个 AI 分析环节的详细提示词。每个 prompt 都是为了在特定环节进行深度的 AI 推理和分析。

---

## 环节 1：产品诊断分析器

**触发时机：** 用户初步介绍产品后

**目的：** 深化对产品的理解，推理目标人群、市场定位、搜索维度建议

### Prompt Template

```
# 产品诊断分析

你是一个资深的 KOL 运营专家，现在要分析一个产品，为后续的红人搜索和匹配做准备。

## 用户提供的产品信息
- 产品名称：{product_name}
- 品类：{category}
- 描述：{description}
- 目标市场：{target_markets}
- 价格定位：{price_point}
- 核心卖点：{usp}
- 竞品：{competitors}（如果有）

## 你的任务

分析这个产品并输出以下内容，**每部分都要有具体的理由**：

### 1. 产品定位总结（1-2 句话）
- 这个产品最核心的竞争优势是什么？
- 它在市场中的位置是什么？

### 2. 目标用户画像（详细）
- 主要年龄段和身份
- 生活方式特征
- 在 TikTok 上的行为习惯
- 购买决策的主要因素

### 3. 搜索维度建议（4-5 个维度）
对于这个产品，应该从哪些维度搜索 TikTok 博主？每个维度给出 2-3 个关键词建议。

维度包括：
- **品类词**：直接搜品类内容的博主（如 "skincare routine"）
- **竞品词**：搜已经推竞品的博主（如 "SK-II haul"）
- **场景词**：搜目标人群的生活方式内容（如 "5-minute skincare"）
- **人群词**：搜目标人群聚集的泛内容（如 "busy mom lifestyle"）
- **趋势词**：当下热门且相关的话题（如 "glass skin"）

每个维度要说明：
  - 为什么选这个维度
  - 这个维度能找到什么类型的博主
  - 预期这个维度的质量（高/中/低）

### 4. 还需要了解的信息
列出 2-3 个后续值得追问的问题，帮助进一步细化策略。

---

## 输出格式

以结构化的 Markdown 输出，让用户能清楚看到每个分析的理由。
```

### 使用示例

**用户输入：**
```
我有一个护肤面膜产品，品牌叫 "HydroGlow"，补水面膜，高端定位，$45 一盒，
目标市场是北美（美国 + 加拿大）。主要竞品是 SK-II 和 Tatcha。
```

**AI 输出：**
```
## 产品定位总结
HydroGlow 是高端补水面膜，定位于 25-40 岁的都市白领和护肤发烧友。
竞争优势在于性价比（比 SK-II 便宜 30-40%）+ 可持续护肤理念。

## 目标用户画像
- 年龄：25-40 岁，主要是 25-35
- 身份：上班族、医美消费者、护肤爱好者、偏自律的生活方式追求者
- TikTok 行为：每周看 3+ 次美妆和护肤内容，会跟风但也理性选择
- 购买触发：看到真实用户测评、对比评测、KOL 推荐 + 用户评价

## 搜索维度建议

1. **品类词** — "hydrating sheet mask" / "moisturizing face mask tutorial"
   - 理由：直接搜品类的用户购买意图最强，容易找到护肤发烧友
   - 博主类型：美妆教程、护肤达人、皮肤科医生转身博主
   - 质量：高

2. **竞品词** — "SK-II mask" / "Tatcha haul"
   - 理由：已经推竞品的博主有购买力认证 + 习惯做产品推荐
   - 博主类型：高端美妆达人、奢侈品测评、生活方式博主
   - 质量：极高，但搜索量较小

3. **场景词** — "5-minute skincare routine" / "anti-aging skincare at 35"
   - 理由：北美上班族重视效率，快速护肤这个话题很火
   - 博主类型：职业女性、快节奏生活方式博主、护肤 Tips 博主
   - 质量：高，但需要二次相关度筛选

4. **人群词** — "busy mom skincare" / "glass skin tutorial"
   - 理由：扩大漏斗，找潜在用户
   - 博主类型：生活方式、家庭、美妆泛博主
   - 质量：中等

## 后续追问
- 你们有没有过往成功合作的博主？（了解有效的博主类型）
- 这次合作的主要目标是什么？（reach vs 销售转化 vs 品牌调性）
- 有预算限制吗？（影响博主层级选择）
```

## 环节 2：关键词生成器

**触发时机：** 产品诊断完成，展示搜索维度后

**目的：** 根据产品定位和 TikTok 趋势，生成 5-8 个高质量关键词，每个词都有搜索意图和博主类型预测

### Prompt Template

```
# 高质量关键词生成

你是一个 TikTok 内容趋势分析师。现在要为一个产品生成最优的搜索关键词。

## 产品背景
{从环节 1 的诊断结果复制}

## 你的任务

基于产品定位和目标市场，生成 5-8 个搜索关键词。**关键要求：**
1. 用"内容词"而不是"产品词"（搜"skincare haul"而不是"HydroGlow mask"）
2. 每个词都要体现当下 TikTok 的趋势（如果你知道最近的热点话题，可以融合）
3. 词的多样性：既有搜索量大的词，也有精准的小词

## 输出格式

```markdown
### 关键词组 1：品类高搜量词
- **关键词：** {keyword}
- **搜索意图：** {intention}
- **预期博主类型：** {influencer_type}
- **预期搜索量：** {expected_volume}（高/中/低）
- **转化潜力：** {conversion_potential}（为什么这个词的人最可能购买）
- **采集目标：** {target_count} 位博主

### 关键词组 2：...
```

## 要考虑的因素
- 目标市场的语言和说话习惯
- 当下 TikTok 的热门话题和挑战
- 竞品在推什么内容
- 目标用户的搜索和消费习惯
```

- **预期搜索量：** 低（搜索量小但精准）

- **预期搜索量：** 中（最近很火的话题）
- **转化潜力：** 中，需要突出"5 分钟补水面膜"的快速性
- **采集目标：** 80 位博主

### 关键词组 4：趋势词 - 抗衰护肤
- **关键词：** "anti-aging skincare over 30"

- **预期搜索量：** 中高（30+ 女性市场很大）
- **转化潜力：** 高，这个人群付费能力强

### 关键词组 5：人群拓展词

## 环节 3：博主匹配评分器

**触发时机：** 采集完成，对每位博主进行评分

**目的：** 对每位博主进行 4 个维度的智能评分，输出 0-100 的综合分

### Prompt Template

```
# 博主多维度匹配评分

你是一个 KOL 匹配专家。现在要对一位博主进行综合评分。

## 产品信息
{产品诊断和目标用户信息}

## 博主数据
- 账号名：{username}
- 粉丝数：{followers}
- 最近活跃度：{recent_activity}
- Bio：{bio}
- 最近视频样本：{recent_videos_summary}
- 邮箱：{email}（如果有）
- 合作信号：{collaboration_signals}

## 评分维度

你要对这位博主进行以下 4 个维度的独立评分，每个维度 0-100：

### 维度 1：内容相关度（0-100）
问题：这位博主的内容与目标产品的匹配程度？
- 100：频繁发布相同品类的内容（如护肤面膜测评）
- 80-99：经常发布相关内容（如护肤教程）
- 60-79：偶尔涉及相关话题（如综合美妆）
- 40-59：相关度较低（如泛生活方式）
- 0-39：基本无关（如美食、娱乐等）

**评分理由：** {reason}

### 维度 2：粉丝匹配度（0-100）
问题：这位博主的粉丝是否与目标用户重合？
- 100：粉丝画像与目标用户完全匹配（如 25-40 岁女性、都市白领）
- 80-99：粉丝主要属于目标用户（80% 重合）
- 60-79：粉丝部分属于目标用户（50-80% 重合）
- 40-59：粉丝有一定重合但偏差较大
- 0-39：粉丝几乎不是目标用户

**评分理由：** {reason}

### 维度 3：合作潜力（0-100）
问题：这位博主是否容易合作、是否有合作意愿？
- 100：有邮箱、bio 中明确写"open to brand collaboration"、最近很活跃
- 80-99：有邮箱、有合作信号、活跃度尚可
- 60-79：有邮箱但活跃度一般、无明确合作信号
- 40-59：无邮箱、需要通过私信、活跃度低
- 0-39：几乎无法联系

**评分理由：** {reason}

### 维度 4：增长趋势（0-100）
问题：这位博主的账号处于什么阶段？
- 100：粉丝和视频互动都在快速增长（周增 5%+）
- 80-99：稳定增长（周增 1-5%）
- 60-79：增长缓慢或持平
- 40-59：粉丝增长停滞，但内容优质
- 0-39：粉丝下降或更新不活跃

**评分理由：** {reason}

## 综合评分计算

基于用户的优先级，计算加权综合分。

用户的优先级设置：
- 快速启动（reach）：内容相关度 30% + 粉丝匹配度 20% + 合作潜力 40% + 增长趋势 10%
- 转化优先（conversion）：内容相关度 40% + 粉丝匹配度 35% + 合作潜力 20% + 增长趋势 5%
- 品牌建设（brand building）：内容相关度 50% + 粉丝匹配度 30% + 合作潜力 15% + 增长趋势 5%

**综合评分：** {weighted_score}

## 最后的定性评价

用 1-2 句话总结为什么应该（或不应该）联系这位博主。
```

### 使用示例

**输出：**
```
## 博主评分：@sarah_skincare_expert

| 维度 | 评分 | 理由 |
|------|------|------|
| 内容相关度 | 94 | 过去 3 个月发布了 12 个面膜相关视频，其中 8 个是补水面膜测评 |
| 粉丝匹配度 | 88 | Bio 明确写"25-40 岁职业女性护肤教程"，互动评论中大量该年龄段用户 |
| 合作潜力 | 92 | 有邮箱，bio 写"open to brand collaboration"，最近每周发布 3+ 视频，活跃度高 |
| 增长趋势 | 75 | 粉丝月增 2%，互动率保持在 4-5%，保持稳定增长但非爆发阶段 |

**综合评分（快速启动优先）：89 分**
= 94×0.3 + 88×0.2 + 92×0.4 + 75×0.1 = 28.2 + 17.6 + 36.8 + 7.5 = 90.1

**建议：强烈推荐立即联系。这位博主内容高度相关，粉丝是完美目标，有明确的合作意愿，是首批联系的核心人选。**
```

## 环节 4：建联建议生成器

**触发时机：** 排序完成，要输出最终建联建议

**目的：** 基于排序结果，给出可操作的分层建联策略和建议

### Prompt Template

```
# 建联策略与建议生成

你是一个 KOL 运营策略顾问。基于采集和评分的结果，要生成最终的建联建议。

## 采集和评分摘要
- 总采集博主数：{total_count}
- A 级（≥80 分）：{a_level_count} 位，平均分 {a_avg}
- B 级（70-79 分）：{b_level_count} 位，平均分 {b_avg}
- C 级（<70 分）：{c_level_count} 位，平均分 {c_avg}

- 有邮箱比例：{email_percentage}%
- 有合作信号：{collab_signal_percentage}%

- 按搜索词来源的质量对比：
  - 品类词：{category_keyword_quality}
  - 竞品词：{competitor_keyword_quality}
  - 场景词：{scene_keyword_quality}
  - ...

## 你的任务

生成以下建议：

### 1. 分层建联计划（可操作）
- **A 级（立即联系）**：建议从这里开始，预计 X% 的合作成功率
  - 【最优路径】有邮箱的 A 级博主（N 位）
  - 【备选路径】无邮箱但有合作信号的 A 级（N 位），需要私信
  - 【建议联系量】建议第一周联系 10-15 位，观察反馈后再扩大

- **B 级（第二梯队）**：A 级反馈不足时的备选
  - 建议第一轮有 20% 的博主无回应，此时启动 B 级联系

- **C 级（保留观察）**：不是立即联系，但可以持续关注

### 2. 联系方式建议
根据博主的邮箱有无、活跃度、合作信号：
- 有邮箱 + 合作信号：优先邮件开发
- 有邮箱但无信号：邮件 + 私信双渠道
- 无邮箱但活跃：私信为主
- 无邮箱且不活跃：降级观察

### 3. 数据洞察
- 哪个搜索词的博主质量最高？（竞品词通常质量最高）
- 是否有出乎意料的高分博主？（可能是新兴创作者）
- 粉丝数与评分的关系？（大号不一定是最优选择）

### 4. 风险提示
- 如果有邮箱比例很低（<20%），要提出是否需要加大搜索量或改变策略
- 如果高分博主都无邮箱，要建议准备高质量的私信模板

### 5. 持续优化建议
- 下一步可以尝试的新搜索词
- 可以调整的评分权重（如"转化优先"而不是"快速启动"）
- 建议多久进行下一次的博主更新

## 输出格式

结构清晰，每个建议都可操作，包含具体的数字和时间表。
```

### 使用示例

**输出：**
```
## 建联计划和建议

### 1. 分层建联计划

**🟢 A 级优先（≥80 分，共 58 位）**

- **【第 1 优先】有邮箱的 A 级博主（38 位）** ← 从这里开始
  建议第一周联系 12-15 位，重点关注 85 分以上的
  预期回复率：40-50%（邮箱渠道通常较高）
  联系文案方向：强调补水效果 + 高性价比 vs 竞品

- **【第 2 优先】无邮箱但有合作信号的 A 级（20 位）**
  需要通过私信，建议等第一批邮件反馈后（3-5 天）再启动
  预期回复率：20-30%（私信转化率较低）
  私信文案建议：简洁 + 直接附上媒体包链接

**🟡 B 级备选（70-79 分，共 92 位）**
- 保持观察，A 级无反馈时启动
- 建议第一轮如果有 <50% 的反馈率，马上启动 B 级

**⚪ C 级观察（<70 分，共 24 位）**
- 暂不联系，但建议每月检查一次是否有账号增长，转为 B 级

### 2. 联系方式建议

| 情况 | 联系方式 | 优先级 |
|------|---------|--------|
| 有邮箱 + "open to collab" | 邮件为主 | P0 |
| 有邮箱，无明确信号 | 邮件 + 私信 | P1 |
| 无邮箱，周发布 3+ 视频 | 私信 | P2 |
| 无邮箱，更新不活跃 | 降级至 C 级 | P3 |

**邮件模板建议方向：**
- 主题：Collaboration Opportunity - HydroGlow Hydrating Mask
- 正文：3 段
  1. 品牌介绍 + 为什么选他
  2. 合作详情（产品、佣金、时间）
  3. 媒体包链接 + 联系方式

**私信模板建议方向：**
- 开场：表扬他的具体内容（"我很喜欢你最近的补水护肤教程"）
- 主体：一句话说明合作（"HydroGlow 是…，想和你合作测评"）
- 结尾：链接或邮箱

### 3. 数据洞察

**🔥 最高质量来源**
- **竞品词（"SK-II mask"）** — 38 位博主，平均分 88 分 ← 转化率最高
  建议：竞品词的博主优先联系，这类博主粉丝购买力最强
  
- **品类高搜量词（"hydrating face mask tutorial"）** — 126 位，平均分 76 分
  建议：体量大但质量参差，从 80+ 的博主开始

**意外发现**
- 有 2 位小 KOL（8K-15K 粉）的评分超过 85 分
  原因：内容极度垂直（100% 面膜相关）+ 粉丝互动率高（8%+）
  建议：小而精的 KOL 也值得联系，容易说 Yes

**粉丝数 vs 评分**
- 粉丝数 100K+ 的博主平均分 72 分（质量反而下降）
- 10K-100K 的博主平均分 79 分（最优区间）
- 建议：不要盲目追求大 V，中腰部 KOL 通常是最优选择

### 4. 风险提示
